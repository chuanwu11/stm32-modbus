# stm32-modbus

在 STM32 上实现的 **Modbus 协议栈**，面向工业现场总线与传感器采集场景。

## 项目状态

🚧 开发中 —— 协议栈核心与示例工程将陆续提交。

## 目标特性

- [ ] Modbus RTU 主机 / 从机（RS-485 半双工，DE/RE 方向控制）
- [ ] Modbus TCP（配合以太网 / WiFi 透传）
- [ ] 常用功能码：`0x03` / `0x04` 读寄存器、`0x06` / `0x10` 写寄存器、`0x01` / `0x02` 读线圈与离散量
- [ ] CRC16（RTU）与 LRC（ASCII）校验
- [ ] RTU 帧边界判定：3.5 字符间隔（定时器）或 UART IDLE 中断 + DMA 接收
- [ ] 寄存器映射表，支持回调式绑定，便于扩展

## 为什么写这个

Modbus 是工业控制、仪表、PLC 领域事实上的通用协议，也是嵌入式岗位 JD 里高频出现的关键词。手写一遍协议栈，能真正吃透**串口不定长帧接收**、**CRC 校验**、**主从轮询时序**这几件事，比调通一个现成库有价值得多。
